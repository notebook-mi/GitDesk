# 2026-10-18

## 第八轮：分支页签新增「合并到当前分支」

用户需求：在「分支」页签加一个分支合并入口（截图圈了工具栏与本地分支行）。

### 实现
- **引擎** `GitEngine.merge_branch(path, source, *, no_ff=False, message=None, author, email)`
  - `source` 支持 `feature/x`（本地）、`origin/main`（远程跟踪）、`refs/...`（完整引用）；
    新增模块级 `_resolve_merge_source()` 统一解析，**本地同名分支优先于远程**
  - 语义对齐 git：`merge_base` 判定 → base==source → `already_merged`；
    base==local 且非 no_ff → `fast_forward`（更新 ref + `reset --hard`）；
    否则 `porcelain.merge(..., no_ff=True, message, author, committer)` 生成双父提交
  - 冲突处理复用 `pull()` 那套：先 `merge_tree()` 只读预检（不动工作区/索引），
    有冲突直接抛错；真合并抛异常或返回冲突时 `_abort_merge(repo, before_head)` 回滚
  - 三个前置拦截：游离 HEAD、`.git/MERGE_HEAD` 存在（上次合并未完成）、工作区有未提交改动
  - `porcelain.merge` 的 author/committer 要传 bytes，格式 `b"Name <email>"`
- **UI** `repos.py`
  - 工具栏「切换到选中分支」后加 `btn_branch_merge`（primary），并入 `_set_busy` 禁用列表
  - `_selected_branch_name()`：按**焦点**决定优先读本地表还是远程表（否则会误用另一张表的残留 currentRow）
  - `_merge_selected_branch()`：未选中 → 提示；选中的就是当前分支 → 提示无需合并；
    confirm 里写明「能快进则快进 / 否则建合并提交 / 冲突自动回滚」
  - `_on_merge_done(result)`：按 `result` 给四种文案（快进/合并提交/已包含/同一提交），
    完成后 `refresh_all()`（状态、分支列表、提交演化图一起更新）

  远程分支、脏工作区拦截、不存在分支、自合并

- 版本 1.2.1

### 注意
- 快进是默认行为（与 git 一致），不会产生合并提交；需要保留合并点时可传 `no_ff=True`（UI 暂未开放开关）
- 远程分支要先「拉取远程分支」才能在本地合并（合并的是 `refs/remotes/...` 的本地快照，不联网）
