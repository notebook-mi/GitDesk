# 2026-10-17

## 第七轮：分支页签「提交演化图」（commit graph / 泳道图）

用户需求：在「分支」页签加一个 Git 提交历史分支演化图。

### 交付结构
- `gitdesk/core/graph.py`：`GraphRow` dataclass（11 字段：sha/short/subject/author/date/lane/parents/refs/connectors/is_merge/is_head）
  + `layout_graph(commits, *, max_lanes=8)`，纯函数、无 Qt 依赖
- `gitdesk/core/gitengine.py::GitEngine.graph(path, limit=80)`：从**所有 refs**（heads + remotes，跳过 `*/HEAD`）遍历，
  一次 `get_refs()` 建 sha→短标签映射，tag 逐个 peel，去重
- `gitdesk/ui/graphview.py::CommitGraphView(QAbstractScrollArea)`：QPainter 自绘
  （行高 26px、泳道宽 18px、圆点/贝塞尔连线/refs 徽标/悬停高亮/tooltip/空状态）
- `gitdesk/ui/pages/repos.py`：`_build_branches()` 改垂直 QSplitter（上=分支表格，下=图）；
  `refresh_graph()` + `_render_graph(path, rows)`（切仓库丢弃过期结果）；`_clear_views()` 清图

### 踩到的三个真坑（都值得记住）
1. **`get_walker` 默认 `order="date"` 不保证拓扑序**（P0）
   - dulwich 1.2.17：`order` 参数值是字符串，`dulwich.walk.ORDER_TOPO = "topo"`
   - 同一 `commit_time` 的提交（脚本连续提交、导入的历史）会按对象比较排序 → **父提交排到子提交上方**，
     泳道判断全乱、连线倒挂
   - 修法：`get_walker(..., order=ORDER_TOPO)` + `layout_graph` 入口加**稳定拓扑校正**（纯函数防御，
     输入已有序时零成本原样返回）
   - 另一个坑：dulwich **先按 `max_entries` 截断、再做拓扑重排** → 同秒提交多时窗口可能不含 HEAD，
     需**有界扩窗**（窗口无 HEAD 则 ×4 重试，≤4 次/上限 5120）
2. **`parents[1:]` 必须查「是否已有泳道在等该父」**（P1，criss-cross 双向合并才暴露）
   - 只给 `parents[0]` 做了检查、第二个父直接开新泳道 → 同一父被两条泳道等待，
     父提交到达时圆点落在最左泳道，先前 fork 线**指向空泳道**（悬空线 + 父子路径断裂）
   - 修法：命中则发 `{from: 本行 lane, to: 该泳道, kind:"merge"}` 且不占泳道
   - 配套不变量（写进测试）：
     ① 任何 connector 端点 ≤「真正出现过圆点的最大泳道」；
     ② 「本行圆点 → 下一行圆点」的连线，下一行必须是本行父提交
   - 共享祖先归属：`survivor = min(lane, *existing)` 保留**最左泳道作主线**，否则主线会被拉到右边
3. **`GitEngine.graph("")` 会打开 cwd 仓库**（P2）
   - dulwich `Repo("")` 等价 `.`；`history()` 同款隐患
   - 修法：`if not path or not os.path.isdir(path): return []`

### 其他经验
- `limit=1` 的 connectors **恒为空**（末行没有下一行），不是缺陷；真正的悬空线在 `limit≥2` 的**倒数第二行**
  （第二父被窗口截断）——需要把「父提交不在本次输出范围内 → 当根、不占泳道不画线」作为规则
- 离屏渲染（`QT_QPA_PLATFORM=offscreen`）没有字体，中文全是豆腐块；**看图要用 `QT_QPA_PLATFORM=windows`**
- 测试数：feature 232 → **299**（+67：graph 算法 43 + 拓扑 11 + criss-cross 8 + 其它 5），自检 106 → **110**
- 版本号 1.1.3 → **1.2.0**
